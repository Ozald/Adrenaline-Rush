# Adrenaline Rush

[![Play on Itch.io](https://img.shields.io/badge/Itch.io-Play%20Now-orange?style=for-the-badge&logo=itch.io)](https://ozald.itch.io/adrenaline-rush)
[![Unity](https://img.shields.io/badge/Unity-2022.3LTS-black?style=for-the-badge&logo=unity)](https://unity.com/)

A short, fast-paced 2D beat-em-up game developed for the **GMTK 2026 Game Jam**! Keep your adrenaline pumpin' by fighting for as long as you can. But be careful. If your combo hits 0, you lose.

## Controls
Arrow Keys -- Movement<br>
Z -- Attack<br>
X -- Parry<br>
Space -- Dash<br>
P -- Pause<br>

## Tech Stack
**Engine:** Unity (C#)<br>
**Art:** Asesprite & Clip Studio<br>
**Audio:** FL Studio & FMOD<br>
